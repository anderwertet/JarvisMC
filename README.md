# JarvisMC

**Голосовой Джарвис в Minecraft.** Нажимаешь V, говоришь — он отвечает голосом
и делает что просишь: открывает инвентарь, перекладывает предметы, пишет в чат,
ставит время, отвечает другим игрокам.

Работает на Fabric 1.21.11. Мост на Python: faster-whisper для речи, любая
LLM через OpenAI-совместимый API или локальный Ollama, голос — Fish Audio
или локальный клон XTTS.

```
🎙  «Джарвис, алмазный меч слот 6»
🔊  «Переложил, сэр.»
📦  меч в шестом слоте хотбара
```

---

## Возможности

- **Голосовой ввод** — push-to-talk на V, VAD сам решает, когда ты закончил
- **Действия в игре** — инвентарь, чат, команды, поворот камеры, перекладывание предметов
- **Понимает неточно** — «меч» найдёт «Алмазный меч», «кирка» — «каменную», опечатки тоже
- **Настройки голосом** — громкость, автоответчик, язык интерфейса, без единого меню
- **Автоответчик** — отвечает в чат, когда упоминают твой ник
- **Два языка** — русский и английский, переключение фразой «enable english mode»
- **Работает без GPU** — облачный мозг и облачный голос, видеокарта не нужна
- **Текст в чат** — строка, начинающаяся с «джарвис», перехватывается модом

## Установка

### 1. Мост

```powershell
git clone https://github.com/USER/JarvisMC.git
cd JarvisMC

py -3.12 -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt

copy keys.env.example keys.env
notepad keys.env
```

Минимум два ключа в `keys.env`:

```ini
FISH_API_KEY=...     # голос Джарвиса — https://fish.audio/app/api-keys
LLM7_API_KEY=...     # мозг, бесплатно — https://dash.llm7.io/#/api-keys
```

```powershell
.\run_server.bat
```

Готово, когда в логе:

```
whisper turbo ready on cuda/int8_float16
fish voice: Jarvis (MCU) J.A.R.V.I.S
Uvicorn running on http://127.0.0.1:8765
```

### 2. Мод

1. Установи Fabric Loader 0.20.1 для 1.21.11.
2. В `mods` положи `JarvisMC-1.21.11.jar` (из [Releases](../../releases)) и Fabric API.
3. Запусти игру, нажми **V**.

## Команды

| Скажи | Что будет |
|---|---|
| «Джарвис, открой инвентарь» | откроет инвентарь |
| «Джарвис, закрой окно» | закроет экран |
| «Джарвис, поставь время день» | выполнит `/time set day` |
| «Джарвис, напиши в чат привет» | отправит сообщение |
| «Джарвис, меч слот 6» | переложит предмет: 1–9 хотбар, 10–36 инвентарь |
| «Джарвис, громкость 70» | громкость голоса 70% |
| «Джарвис, включи автоответчик» | ответы в чат, когда зовут по нику |
| «enable english mode» | интерфейс и ответы на английском |
| «включи русский режим» | обратно на русский |

## Как устроено

```
🎙 микрофон
   └─ мод (Java) ──HTTP──┐
                         │
                   мост (Python)
                   ├─ STT   faster-whisper turbo
                   ├─ LLM   облако или Ollama
                   └─ TTS   Fish Audio / XTTS / Kokoro / Piper
                         │
   ┌─────────────────────┘
   └─ мод: играет звук, выполняет действия, рисует статус
```

| Модуль | Роль |
|---|---|
| `app/server.py` | FastAPI: `/health`, `/stt`, `/chat`, `/agent`, `/tts`, `/volume` |
| `app/stt.py`, `app/audio.py` | распознавание и захват с адаптивным гейтом |
| `app/agent.py` | планировщик `{say, actions}` с белым списком действий |
| `app/backends.py` | OpenAI-совместимое облако + Ollama с фолбэком |
| `app/fish.py`, `app/eleven.py` | облачные голоса |
| `app/tts.py`, `app/diction.py` | обработка звука и обращение «, сэр» |

Подробный разбор с замерами — в [docs/TECHNICAL.md](docs/TECHNICAL.md).

## Настройки

Всё через переменные среды или `keys.env`:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `JARVIS_LLM` | `auto` | `auto`, `ollama`, `llm7`, `deepseek`, `custom` |
| `JARVIS_MODEL` | `qwen2.5:3b` | локальная модель Ollama |
| `JARVIS_STT_MODEL` | `turbo` | `turbo` или `small` (быстро, но врёт по-русски) |
| `JARVIS_SILENCE` | `0.75` | сколько тишины завершает фразу |
| `JARVIS_MAX_REPLY` | `320` | предел длины ответа |
| `JARVIS_FISH_RU` / `_EN` | id голосов | любой голос с fish.audio |

## Если не работает

| Симптом | Причина |
|---|---|
| «Мост недоступен» | не запущен `run_server.bat` |
| `429` в логе | кончилась бесплатная квота, подождать или сменить ключ |
| Речь распознаётся мусором | выбрать микрофон: `http://127.0.0.1:8765/devices` |
| Нет звука | пустой `FISH_API_KEY` и нет локальных моделей голоса |
| `cublas64_12.dll is not found` | поставить GPU-сборку torch или сменить на CPU |

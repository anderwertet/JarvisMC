# JarvisMC

Голосовой ассистент Джарвис для Minecraft 1.21.11 (Fabric). Говоришь в микрофон —
он отвечает голосом и выполняет действия в игре: открывает инвентарь, перекладывает
предметы, пишет в чат, ставит время, меняет громкость своего голоса.

Состоит из двух частей:

- **мод** `JarvisMC-1.21.11.jar` — тонкий клиент, только отправляет звук и играет ответ;
- **мост** на Python — распознаёт речь, думает моделью, синтезирует голос.

Всё в этом архиве — это мост. Мод лежит в папке `mod/`.

---

## Что нужно

| | |
|---|---|
| ОС | Windows 10/11 (Linux тоже пойдёт, но батника нет) |
| Python | 3.12 |
| GPU | не обязателен, но с NVIDIA быстрее в 5–10 раз |
| Minecraft | 1.21.11 + Fabric Loader 0.20.1 + Fabric API |
| Интернет | нужен для облачного мозга и облачного голоса |

Модели весят много, поэтому в архив не входят: Whisper скачается сам при первом
запуске (~1.6 ГБ), голос Fish работает по API.

## Установка моста

```powershell
# 1. склонировать или распаковать, зайти в папку
cd C:\JarvisMC

# 2. окружение
py -3.12 -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install -r requirements.txt

# 3. ключи: файл keys.env уже лежит в проекте, осталось вписать значения
notepad keys.env
```

В `keys.env` заполни минимум два поля:

```
FISH_API_KEY=...        # голос Джарвиса, https://fish.audio/app/api-keys
LLM7_API_KEY=...        # мозг, бесплатно, https://dash.llm7.io/#/api-keys
```

Без ключей мост всё равно запустится: будет отвечать локальной моделью Ollama
(если она установлена) и молчать голосом.

```powershell
# 4. запуск
.\run_server.bat
```

В логе должно появиться:

```
whisper turbo ready on cuda/int8_float16
fish voice: Jarvis (MCU) J.A.R.V.I.S
brain llm7/gpt-oss:20b
Uvicorn running on http://127.0.0.1:8765
```

Проверка: открой `http://127.0.0.1:8765/health` — должен вернуться JSON с
`"ok": true`.

## Установка мода

1. Поставь Fabric Loader 0.20.1 для 1.21.11.
2. В папку `mods` положи:
   - `mod/JarvisMC-1.21.11.jar`
   - `fabric-api` для 1.21.11 (скачать отдельно с Modrinth)
3. Запусти игру. Клавиша **V** — говорить.

Первый запуск создаст `config/jarvis-voice.json` с настройками моста.

## Что говорить

| Фраза | Что произойдёт |
|---|---|
| «Джарвис, открой инвентарь» | откроет инвентарь |
| «Джарвис, закрой окно» | закроет экран |
| «Джарвис, поставь время день» | выполнит `/time set day` |
| «Джарвис, напиши в чат привет» | отправит сообщение |
| «Джарвис, меч слот 6» | переложит предмет (1–9 хотбар, 10–36 инвентарь) |
| «Джарвис, громкость 70» | громкость голоса 70% |
| «Джарвис, включи автоответчик» | будет отвечать в чат, когда упоминают твой ник |
| «enable english mode» | интерфейс и ответы на английском |
| «включи русский режим» | обратно на русский |

В чат можно писать текстом: строка, начинающаяся с «джарвис», перехватывается
модом и не уходит на сервер.

## Как это устроено

```
микрофон → мод → HTTP → мост:
                         STT (faster-whisper) → LLM (облако или Ollama) → TTS (Fish)
                       ← JSON + PCM
мод: играет звук, выполняет действия, рисует строку состояния
```

| Файл | Что делает |
|---|---|
| `app/server.py` | FastAPI: `/health`, `/stt`, `/chat`, `/agent`, `/tts`, `/volume` |
| `app/audio.py` | захват микрофона и VAD |
| `app/stt.py` | faster-whisper, адаптивный гейт |
| `app/agent.py` | планировщик: JSON `{say, actions}` и белый список действий |
| `app/backends.py` | транспорт к моделям: OpenAI-совместимое облако + Ollama |
| `app/fish.py` | голос Fish Audio |
| `app/tts.py` | выбор движка и обработка звука |
| `app/diction.py` | обращение «, сэр» в каждой фразе |

Ключи читаются из `keys.env` (переменные среды имеют приоритет).

## Настройки

Всё через переменные среды или `keys.env`:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `JARVIS_LLM` | `auto` | `auto`, `ollama`, `llm7`, `deepseek`, `custom` |
| `JARVIS_MODEL` | `qwen2.5:3b` | локальная модель Ollama |
| `JARVIS_STT_MODEL` | `turbo` | `turbo` (точно) или `small` (быстро, но врёт по-русски) |
| `JARVIS_SILENCE` | `0.75` | сколько тишины завершает фразу |
| `JARVIS_FISH_RU` / `JARVIS_FISH_EN` | id голосов | можно подставить любой голос из fish.audio |
| `JARVIS_XTTS` | `1` | локальный клон вместо Fish (нужны модели) |
| `JARVIS_MAX_REPLY` | `320` | предел длины ответа в символах |

Полный список — в `keys.env.example` и в шапке `app/config.py`.

## Если не работает

| Симптом | Причина |
|---|---|
| «Мост недоступен» | не запущен `run_server.bat` или другой порт |
| Ответов нет, в логе `429` | кончилась бесплатная квота провайдера, подождать или сменить ключ |
| Речь распознаётся как мусор | проверь микрофон: `http://127.0.0.1:8765/devices` |
| Нет звука | в `keys.env` пустой `FISH_API_KEY` и нет локальных моделей голоса |
| `cublas64_12.dll is not found` | поставь GPU-сборку torch или запусти на CPU |
